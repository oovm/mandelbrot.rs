简单解释下理论物理学这种做法为什么违背了标准数学分析还能生效吧.

标准分析认为, 这里差一个无穷小量, 差值任意小, 所以可以划等号. 然而序数分析(非标准分析的一种)认为, 这里差一个极限序数, 极限序数不是任意小, 所以不能划等号.

那为什么序数分析反而能给出物理试验测得的结果呢?

物理学家们认为虽然其测量结果是 1, 但是在更小的尺度上, 还有其他各种各样的物理现象, 会对其造成扰动, 这种扰动一般是无关紧要的, 你把它当成 1, 做四则远算完全没问题.

但是, 在特殊情况下, 这种低层次的效应会叠加起来, 更高尺度上造成可观测效应. 那你就不能把他当 1 了, 而是要把他当成一个极限序数, 用序数分析来处理.

至于这个扰动到底多小是不重要的, 反正不是无限小, 那就假定他是 λ, 和 ε 做出区分. 然后基于 λ 这个基准, 去和别的的效应耦合, 运算, 相消.

要注意, λ 不适合看做一个常数, 他和重力常数 G 这种不一样, λ 的数值不重要, 重要的是耦合关系. 

恰恰就是这种思想, 完美对应了序数分析理论, 因此流体力学, 非线性动力学, 相变理论, 量子场论, 弦论等等领域, 都不怎么适用标准分析.
